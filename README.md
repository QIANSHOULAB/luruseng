# 录入僧

施主去玩，贫僧填表。（2026-10-29 由「搬工」改名；旧的配置、名单、数据库、账本第一次打开时自动搬过来）

把一个文件夹里的刀具破损记录照片（照片、扫描件、HEIC 都行）送给 Gemini，认出每一条 TOOL BROKEN RECORD，边干边写进一本跟公司那本长得一样的 Excel。

- 网站（下载、怎么用）：https://qianshoulab.github.io/luruseng/
- 网页版（不用装，电脑、手机都行）：https://qianshoulab.github.io/luruseng/web/ 。功能跟电脑版一样，东西存在那个浏览器里（⚙ 里能备份）。代码在 `web/`：`core.js` 跟 `engine.py`、`kb.py`、`tables.py` 是同一套规矩，改一边要改另一边；`web/test/e2e.py` 让两边拿同样的照片各出一本表，一格一格对。
- 联系制作人（修改建议、想要的功能）：oilsongchengmin@gmail.com（程序里 ⚙ →「联系制作人」）
- 发新版：改 `bangong/engine.py` 的 `VERSION`，在 `changes.md` 顶上加一段「## 新版本号」写更新了啥，推到 main。
- 下载：https://github.com/QIANSHOULAB/luruseng/releases/latest/download/luruseng.exe （双击就能用，不用装 Python；直接在「下载」里双击也行，它会在旁边建「录入僧」文件夹搬进去）
- 用法：填钥匙（Google AI Studio 的 API Key，可以填两把），点「选照片…」挑照片，点「开始工作」。挑的照片复制进「图片文件夹」（默认 exe 旁边的「待识别」，没有就当场建），原照片原地不动；待识别里已经有的、以前干过的（按内容认，改了名也认得）不再复制。换文件夹：在「图片文件夹」框里改路径。还没钥匙：点钥匙框后面的「免费领钥匙」，打开网站上的教程页 `key.html`（「再领一把」跳到钥匙 2 那段）。
- ⚙ 设置（右上角）：开机自动启动、点 × 只收起、干完自动打开、保留原图、自动更新、记住钥匙、桌面和开始菜单图标、发数据给方丈。用过录入僧的电脑全开照旧；新装的电脑开机启动关、× 直接退出、来图就干不勾，其余开。「发数据给方丈」谁的电脑都默认关。
- 发数据给方丈（v1.9.8 起，默认关）：开着时每批认完，把这批怎么认的（每遍认成什么、表里最后写了什么、哪些格子红/橙）、模型看到的照片（缩到 1600 像素）、后来人在表里改过的格子（表存过盘就跟刚认完时的原样比），闲着时送到方丈网盘的「录入僧回传」文件夹。先落在 `识别结果\.回传\`，断网不丢，发过的不重发。接口是方丈谷歌账号里的 Apps Script（代码在 `collector/`），只收不给。打开开关时当场问一声网盘通不通。
- 来图就干：往「待识别」放照片，30 秒内没再放新的就自己开工；自动开工的不弹 Excel 和核对窗口。认失败留在原地的照片不会被反复重试，等有新照片进来再一起干。⚙ 里开着「点 × 只收起」时，点 × 只是收起窗口；真要退出，先去掉「来图就干」的勾。
- 自动更新（v1.9.1 起新装的电脑默认关着；Song 的电脑开着）：开着时每 6 小时查一次网站上的 `version.txt`，有新版就下载成「录入僧.new.exe」；关着时照样每 6 小时查，有新版只弹卡片说明更新了啥（来自 Release 里的 `changes.md`，就是仓库根目录的 `changes.md`），点「现在更新」才下载、马上换，也可以点「以后都自动更新」；点「以后再说」后右上角 ⚙ 旁边留一个蓝色「新版本」小按钮。手动也行：把新版 exe 改名「录入僧.new.exe」放到 `录入僧.exe` 旁边。它会先试新版能不能打开，能就自己换上、重开，用过的更新包挪进「待删除」（上一级有「待删除」就用它，没有就在程序文件夹里建）；记录在 `更新日志.txt`。只在空闲时换：没在干活、核对、投喂，两分钟没人碰。
- 正名：要是从别名（比如「录入僧测试版.exe」「luruseng.exe」）跑起来的，它会把自己抄回 `录入僧.exe` 再重开（`录入僧.exe` 已经一样新就直接开它），别名 exe 挪进待删除。
- 只开一个：再双击图标只会把已经开着的窗口亮出来。`.录入僧状态.json` 写着版本、在不在干活、上一批结果（不含钥匙），给远程看。
- 每张认两遍对答案：第二遍用拉过对比度的图；两遍对得上就收，对不上认第三遍按多数定；几遍认得不一样的格子标红，O 列写明几遍各认成什么。一张照片 2～3 次请求。
- 认完先整理写法（不改内容）：零件号、机台去空格、统一横杠；描述开头混进去的刀号（T44 …）挪回 T NO.，几把刀写成「T6, T7」；ø、⌀ 等统一成 Φ；班次「白/夜/Day/Night」统一成 D/N。
- 设计记录（每一步为什么这么定）：`docs/设计记录.md`
- 编号：照片按拍摄时间（EXIF，没有就用文件时间）编号 1、2、3……，表里 A 列 No. 就是照片编号：第 N 张照片的记录在 No. N 那一行。一张照片有两条记录就两行同一个编号；认不出、失败的也留一行，编号不会错位。
- 编号照片：认完以后，在每张照片最空的那个角印上大红编号（白底红框；四个角都有字就在顶上加一条白边写），存成 `已识别\<这次的时间>\01.jpg、02.jpg……`，干完跟 Excel 一起自动打开，人对着核。送去识别的永远是原图，编号不会被当成内容。原图原封不动放在同一个文件夹的 `原图\` 里。
- 照片自动转正：认单子时模型顺便报单子标题在照片哪一边（几遍按多数定），印编号的那份照片按它转正，核对窗口里看到的就是正的；原图不动。万一转错，核对窗口的 ↺ ↻ 点一下就转回来（存回那张编号照片）。
- 核对：主窗口的「核对」按钮（每批干完也会自动弹出）打开核对窗口：左边是编号照片，第一张就是 1；「上一张 / 下一张」或键盘 ←→ 翻页，输入编号回车直接跳；右边列出表里同一号的记录，标红的字段在这里也是红的；双击照片用系统看图打开原尺寸。顶上可以换看以前的批次。（v1.9.5 起顶上有「打开表」：看到哪批开哪批的表）
- 核对里直接改（v1.10.0）：右边点哪格改哪格，直接写回那批的表（电脑版改 Excel 文件，网页版改浏览器里存的那批，下载的表跟着变）。红格子底下列出几遍认出来的不同写法，点一个就填上；认对了点「对的」只去掉红；回车＝「改好了」，Esc 收起。打的字照认字的规矩整理（日期按那批的年份、数字变数字、班次变 D/N、零件号去空格大写），打错了（数字格打了字母、班次不是 D/N）还红着、提示写为什么。改过、核过的格子淡绿（E2EFDA，字 375623）；这一格的核对提示跟着删，数量对上了三格一起不红；一条的红格子全处理完，O 列写「✓ 人核过」，这条自己进这个类别的样板资料（来源「核对 批次号 #编号.第几条」，同一条再改换掉上次那份，又改红了拿掉）。表在 Excel 里开着改不进去（提示关掉 Excel 再点「改好了」）；正在干的那批先不让改（干完存盘会整本重写）。v1.10.0 起每批干完只弹核对窗口，不再自己打开 Excel。v1.10.1 起核对里 BTMP 空着就不列（换刀调试单上没有这一格；表里那一列照留，贴进公司表不错位）。v1.10.2 起单子上没写 BTMP 的，表里照抄 TOTAL SCREENED（公司那本里这两格每行都一样），核对里不列这份抄的；核对里改 TOTAL，抄的 BTMP 跟着改（打错了就清空）；单子上真写了 BTMP 且跟 TOTAL 不一样的，照写、照列、不跟着变。
- 数据库（越认越准）：主窗口「放入样板资料」（v1.9.4 起叫这个，说明里不提公司）选「刀单」，再选公司的 TOOL BROKEN RECORD（可多选；.xlsx、.xlsm、老的 .xls、.csv 都行，别的系统导出的「假 .xls」也认得；核对过的录入僧结果表也行；不像刀单的表——没有 DATE、MACHINE 表头——一条都不吃，免得别的单子串进来），每一页的记录和 NAME 页的工号名字都吃进 `录入僧.exe` 旁边的 `数据库.sqlite`；或者把表丢进旁边的 `投喂\` 文件夹，每次开工前自动吃（改过的会重吃，同一条记录不会重复）。识别时以数据库为准：出现过的机台、零件号、刀具描述随请求告诉模型；认出来的值跟库里的只差一个容易看错的字（O/0、I/1、S/5、B/8…）就改成库里的写法，标橙；库里没见过的机台、刀具描述，模型认得清就不标，拿不准才标红（没见过的零件不标，新零件常有）。不按零件对历史（零件、刀、MO 之间的老关系不拿来标红）。录入僧自己认出来的不进库，只认喂进去的表。数字和日期每次都是新的，靠 PASSED+FAILED=TOTAL 这类检查兜底。数据库只在本机，不上 GitHub。命令行：`录入僧.exe --feed 表.xlsx`。
- 类别（v1.9）：主窗口「类别」下拉选这次认的是哪种单子。「刀单」是内置的那套专属优化（上面说的提示词、整理规则、名单、数据库）。别的单子点「＋ 新建类别」起个名字，就多一个文件夹 `类别\<名字>\`，里面是它自己的 `数据库.sqlite` 和 `投喂\`，跟刀单互不串味。还没放过表的类别先「认全部内容」：模型拿单子上印好的栏目名当列名，出一本表（`识别结果_<时间>_<类别>.xlsx`）；人改对了点「放入样板资料」选这个类别放进去，第一本的表头就定成它的列（以后多出来的列接在后面）。之后按这些列认：每列出现过的值拿来提示和纠错（只差一个容易看错的字就改成库里的写法，标橙），几行改对过的记录放进提示词当例子，数字列只收数字。两遍对答案、拿不准标红、照片印编号跟刀单一样。命令行 `--cli` 按窗口里选的类别认，环境变量 `BANGONG_CATEGORY` 可以指定别的。
- 名单：`录入僧.exe` 旁边的 `名单.txt`，一行一个「工号/名字」（记事本就能改）。有名单时：名单会告诉模型；单子上只写工号、只写名字、或者写得潦草，SETTER 按名单补成完整的「工号/名字」；工号和名字跟名单对不上的标红；不在名单里的新人，认得清就不标。名单不进 GitHub。（v1.9.5 起：右边「编辑名单」在窗口里直接改，存的还是这个 名单.txt）
- 表格：B 到 N 列跟公司 TOOL BROKEN RECORD 一格不差（DATE、MACHINE、PART NUMBER、MO、OPR NO.、T NO.、DESCRIPTION、BTMP、TOTAL SCREENED、PASSED、FAILED、SHIFT、SETTER），复制 B 到 N 的数据行整块贴进公司表。O 列是核对提示，不用贴。
- 标红（只标拿不准的，认得清的不标）：模型自己说拿不准的字段（每条记录多回一项 unsure）、有看不清的字（□）、数字不是数字、SHIFT 不是 D/N、PASSED + FAILED ≠ TOTAL SCREENED。日期从不标红（错了无所谓），认不出就照原样写。只看红格子就行。
- 日期：新加坡写法日在前；年份一律按今年（认成别的年份也改成今年）；日期从不标红。
- 每批 5 张，每张单独一次请求，5 张同时发；每批干完存一次盘。
- 这一批的编号照片和原图在 `已识别\<这次的时间>\`，跟 `识别结果\识别结果_<这次的时间>.xlsx` 一一对应。失败的留在原地，下次点开始会重试。日志在 `识别结果\录入僧日志.txt`。主窗口「最新结果」直接打开最新那本表；「所有结果」把每一批列出来（时间、类别、几张），点「打开表」「核对」就行，底下留着「打开结果文件夹」。
- 干过的照片记在账本里（按文件内容算指纹），改了名也不会重干，会挪进 `已识别\重复\`。
- 每分钟次数到顶：按谷歌回的 retryDelay 等（没给就等 60 秒）接着干。当天额度用完：先换钥匙 2；两把都用完就等到太平洋时间半夜（新加坡下午 3 点，冬令时 4 点）额度刷新后接着干。
- 谷歌说预付余额用完、钥匙无效、模型不存在：直接停，把谷歌原话写进日志。
- 钥匙只存在本机 `%APPDATA%\录入僧\config.json`，请求时只走 URL 参数 `?key=`。
- 无窗口跑一轮：`录入僧.exe --cli [文件夹]`（读同一份配置）。
