施主去玩，贫僧填表

刀具破损记录（TOOL BROKEN RECORD）拍照丢进文件夹，Excel 表自己出来。一张照片一行，照片上印好编号对着核；认不准的格子标红，只看红的就行。别的单子也能教它认：建个类别，放几本改对的表进去就行。

手机上用 网页版，不用装。要电脑版：把这个网址发到电脑上再下载。
下载 Windows 版 用网页版 不用装，手机也行 Windows 10 / 11 · 约 30 MB · 免费 · 所有版本

三步，然后施主去玩

1

下载，双击

点上面的蓝按钮。最好先建个文件夹放进去，比如 D:\录入僧。

直接在「下载」里双击也行：它会在旁边自己建一个「录入僧」文件夹搬进去，照片、表格、数据库都在那里面，不撒一地。

2

填钥匙

去 Google AI Studio 用谷歌账号登录，点 Create API key，复制，贴进「钥匙 1」。完全免费，老衲不打诳语。

第一次弄？看领钥匙教程。打死别绑卡，就不会花钱。

3

丢照片，点开始

照片放进「待识别」文件夹，点「开始工作」。干完自动打开表格和核对窗口，第几张照片对表格第几行。

不是刀单？先在「类别」里选好（或者「＋ 新建类别」）再开始。勾上「来图就干」，以后照片一放进去它就自己开工。

第一次打开，会遇到两道门只有第一次

浏览器说「不常下载」

  • Chrome：点 保留
  • Edge：点 … → 保留 → 仍然保留

Windows 蓝框「已保护你的电脑」

  • 点 更多信息 → 仍要运行
  • 没花钱买签名证书，Windows 不认识它，就这么回事。

丑话说在前面

  • 照片会发给谷歌 Gemini 去认，用的是你自己的钥匙和额度。免费额度用完了，它会自己等额度恢复再接着干。
  • 表格、名单、数据库、照片都只在你自己电脑上，不往别处传。钥匙也只存在你电脑上；公用电脑可以在右上角 ⚙ 里关掉「记住钥匙」。
  • 越用越准：点「放入数据库」把公司核对过的 TOOL BROKEN RECORD 放进去，名字、刀具、机床它就认得越来越熟。
  • 不只刀单：点「＋ 新建类别」起个名字（比如质检单），它先把单子上的内容全认出来；你改对了点「放入数据库」放进这个类别，表头就定成它的列，越放越准。每个类别一个自己的数据库，跟刀单互不串味。
  • 有新版会告诉你：每 6 小时查一次，出了新版就弹出来告诉你更新了啥，点「现在更新」它自己下载、自己换上，设置和数据都不动。嫌麻烦就点「以后都自动更新」，以后空闲时自己换。
  • 不留原图也行：⚙ 里关掉「保留原图」，认完的原片扔进回收站，省一半硬盘。
