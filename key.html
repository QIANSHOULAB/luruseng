领钥匙

完全免费，老衲不打诳语

录入僧认照片，靠的是谷歌的 Gemini。钥匙（API Key）就是谷歌发给你的通行证：一长串字母数字，贴进录入僧的「钥匙 1」就能开工。有谷歌账号就能领，不绑卡，不花钱，两分钟的事。

去谷歌领钥匙 打开的是谷歌官方的 Google AI Studio（aistudio.google.com/apikey）

四步，钥匙到手

1

登录

点上面的蓝按钮，用谷歌账号登录，Gmail 那个号就行。第一次进去会让你同意条款，同意就是了。

没有谷歌账号？先注册一个，也不要钱。

2

找到钥匙

新号一进去，谷歌通常已经顺手给你建好了一把，就在 API Keys 页的列表里。没有的话点 Create API key 建一把。

3

复制

点开那把钥匙，整串复制下来，一个字都别漏。现在新领的钥匙是 AQ. 开头的一长串。

4

贴进录入僧

粘贴到「钥匙 1」，点「开始工作」。完事，施主可以去玩了。

⚙ 里开着「记住钥匙」的话，下次打开不用再贴。

钥匙 2：备胎，不是外挂可以空着

  • 它干嘛用：免费钥匙每分钟、每天能问谷歌的次数有上限（多少谷歌说了算，AI Studio 里看得到）。填了钥匙 2，钥匙 1 到顶了录入僧就换钥匙 2 接着干。
  • 额度按「项目」算，不按钥匙算：同一个项目里建再多把钥匙，也是同一份额度，填了等于没填（录入僧连两个框填同一把都会拦你）。所以钥匙 2 得是另一个项目里的：在 AI Studio 左边 Dashboard → Projects 里管项目，在另一个项目里 Create API key。
  • 别拿它薅羊毛：谷歌封过「把好几个项目当一个用、绕开额度」的项目，有人中过招。天天都不够用的话，正路是给项目开结算、升级额度，别靠一堆免费钥匙硬顶。

丑话说在前面老衲不打诳语

  • 真免费：领钥匙、用免费档，不绑卡，一分钱不花。录入僧默认用的 gemini-3.5-flash-lite 就在谷歌的免费档里。
  • 有上限：免费档每分钟、每天的次数有限。到顶了录入僧会自己等一等再接着干，急也没用。
  • 免费的代价：谷歌条款写明，免费档传上去的照片和认出来的结果，会被拿去改进他们的产品，还可能有人工看；条款原话还劝你别往免费档传敏感、机密、个人的信息。刀单上有名字和工号——公司的单子，最好让公司给项目开结算走付费档（按用量算钱，价目表），付费档的内容不拿去改进产品。
  • 钥匙当密码管：别发群里、别贴网上，谁拿到谁就花你的额度（开了结算就是花你的钱）。录入僧只把钥匙存在你自己电脑上。
  • 有的地方用不了：谷歌的 AI Studio 不是哪儿都开放，中国大陆、香港就用不了；新加坡、马来西亚没问题（谷歌的名单）。
